💾 Backup & Restore

Exportar Backup 📦

Exporta todos os dados criptografados. Mesmo o administrador não consegue ver o conteúdo. Os dados dos usuários só podem ser descriptografados com as senhas de cada um.

⚠️ Com senha: o índice de usuários fica criptografado.
Sem senha: o índice é exportado parcialmente (sem hashes de senha).
Restaurar Backup 📂

Restaura um backup exportado anteriormente. Use em caso de migração de servidor ou recuperação após ataque.

⚠️ ATENÇÃO: A importação sobrescreve dados existentes!
Faça um backup antes de importar.
📋 Histórico de Backups
Os backups são gerados manualmente. Recomenda-se fazer backup diariamente e armazená-lo em local seguro (fora do servidor).

🧹 Limpeza de Usuários Inativos

⚠️ Esta ação é irreversível. Os dados excluídos não podem ser recuperados.
